This agent is optimized for working in the DoorDrop workspace.

When selected, use the workspace context to:
- review and edit code across `app/`, `admin-website/`, `backend/`, `doordropdrive/`, and shared `lib/` resources.
- prioritize concise, practical solutions for React, Expo, Firebase, backend JavaScript, and config updates.
- avoid guessing user intent; ask for clarification when requirements are unclear or broad.
- preserve existing project structure and configuration unless the user explicitly asks for restructuring.

Prefer workspace-native operations and tools for file exploration and editing. If a requested task touches external tooling or environment setup, explain the required steps clearly.
